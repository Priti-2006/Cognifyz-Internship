## Task Details

### Level 1 — Task 1: Text Based Game
**File:** `Level1/task1_text_game.py`

A console-based game offering two modes:
- **Quiz Game** — 5 multiple-choice questions with score tracking
- **Number Guessing Game** — guess a random number (1–100) within 7 attempts

Built using conditional statements (`if/elif/else`) to manage game logic and flow.

**Run it:**
```bash
cd Level1
python task1_text_game.py
```

---

### Level 1 — Task 2: Number Patterns
**File:** `Level1/task2_number_patterns.py`

Generates 5 types of number patterns using nested loops:
- Right Triangle
- Pyramid
- Inverted Triangle
- Diamond
- Floyd's Triangle

**Run it:**
```bash
cd Level1
python task2_number_patterns.py
```

---

### Level 2 — Task 3: CRUD Operations
**File:** `Level2/task3_crud_operations.py`

A console-based Task Manager implementing all 4 CRUD operations:
- **Create** — add a new task
- **Read** — view all tasks
- **Update** — edit task details
- **Delete** — remove a task

Tasks are stored in-memory using a `Task` class and a Python list.

**Run it:**
```bash
cd Level2
python task3_crud_operations.py
```

---

### Level 2 — Task 4: Temperature Converter
**File:** `Level2/task4_temperature_converter.py`

Converts temperatures between:
- Celsius ↔ Fahrenheit
- Celsius ↔ Kelvin

Includes input validation and a menu-driven interface.

**Run it:**
```bash
cd Level2
python task4_temperature_converter.py
```

**Sample Test Cases:**
| Input | Output |
|---|---|
| 100°C | 212.00°F |
| 32°F | 0.00°C |
| 0°C | 273.15K |
| 300K | 26.85°C |

---

### Level 3 — Task 5: CRUD with File Storage
**File:** `Level3/task5_crud_with_file.py`

Enhances the Task 3 CRUD app with **persistent file storage**:
- Tasks are automatically saved to `tasks_data.txt` after every change
- Tasks are automatically loaded back when the program restarts
- Includes error handling for file read/write operations

**Run it:**
```bash
cd Level3
python task5_crud_with_file.py
```

**Tested for persistence:** Added a task, exited the program, reopened it — task was still present.
